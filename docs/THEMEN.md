# Themen-Pool — Erklär-Shorts

Kurzvideos, die Phänomene, Ereignisse und Dinge erklären. Optimiert für Short-Form (TikTok, Reels, Shorts):
In der **ersten Sekunde** passiert etwas Absurdes, das erst danach erklärt wird. Format und Regeln → `docs/STYLEGUIDE.md` §6–§8.

**Signatur: Ein Video, eine Farbe.** Alles ist Off-White/Schwarz bzw. Archiv-Graustufen, nur das Objekt der Geschichte
trägt Farbe (Melasse = Bernstein, Radium = Leuchtgrün …).

Status: ☐ offen · ◐ in Arbeit · ☑ fertig
